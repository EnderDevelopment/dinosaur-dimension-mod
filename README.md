# Dinosaur Dimension Mod

Explore a new dimension filled with dinosaurs in Minecraft 1.20.1

## Features

- Custom dimension with unique blocks and entities
- Portal system to travel between dimensions

## Requirements

- Minecraft 1.20.1
- Fabric Loader
- Fabric API

## Installation

1. Download the mod JAR file from the releases page.
2. Place the JAR file in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

1. Craft the Dinosaur Portal block using obsidian.
2. Place the portal block to create a portal to the Dinosaur Dimension.
3. Step through the portal to explore the new dimension.

## Configuration

The mod does not have a configuration file. All settings are hardcoded.
